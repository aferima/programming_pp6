Програмний проєкт №6

Варіант №10 — Гра «Вгадай число» з використанням сопрограм

Виконала: Феріма Анна
Група: К-24

Програма реалізує гру «Вгадай число», у якій беруть участь дві сопрограми:

Загадувач (thinker) — загадує число від 1 до 100.
Вгадувач (guesser) — намагається знайти загадане число.

Після кожної спроби загадувач повертає відповідь:

-1 — запропоноване число менше за загадане;
0 — число вгадано;
1 — запропоноване число більше за загадане.

Вгадувач використовує бінарний пошук: на кожному кроці обирає середину можливого діапазону чисел. Завдяки цьому число можна вгадати не більше ніж за 7 спроб.

Основна програма керує взаємодією сопрограм і виводить усі кроки гри.

Переможець визначається за номером кроку:

- якщо число вгадано на парному кроці — перемагає загадувач;
- якщо на непарному — перемагає вгадувач.

Структура проєкту

 DuplexCoroutine.h - забезпечує призупинення, відновлення та обмін даними з сопрограмами 
 Players.h - містить оголошення сопрограм та основних функцій 
 Players.cpp - реалізує загадування числа та його пошук 
 GuessGame.h - оголошує функції проведення гри та збереження результату 
 GuessGame.cpp - керує грою, виводить кроки та визначає переможця 
 main.cpp - зчитує вхідні дані з файлу та запускає ігри 
 games.txt - приклади ігор для демонстрації 
 games_with_errors.txt - приклади неправильних вхідних даних для перевірки помилок 
 CMakeLists.txt - налаштування збирання проєкту 

Вхідні дані

Програма читає дані з текстового файлу games.txt.

Кожен рядок відповідає одній грі та містить:

- число від 1 до 100, яке потрібно вгадати (лише цифри, без знака, не більше трьох цифр: 25 і 025, але не +25 чи 0025);
- або слово random, якщо число потрібно обрати випадково.

Приклад файлу:

50
25
73
42
random

Також можна додавати коментарі після символу #. Порожні рядки ігноруються.

Якщо рядок містить помилку (наприклад, число 150, текст замість числа або зайві значення), програма повідомляє номер рядка та причину помилки, пропускає його й продовжує роботу.

Для перевірки цієї можливості створено окремий файл games_with_errors.txt.

Якщо файл не вдалося відкрити або в ньому немає жодного правильного рядка, програма виводить повідомлення про помилку й завершується з кодом 1.

Компіляція за допомогою g++:
g++ -std=c++20 main.cpp GuessGame.cpp Players.cpp -o guess_game

Запуск програми:
./guess_game

За замовчуванням використовується файл games.txt у поточній робочій папці.

Запуск із файлом для перевірки помилок:
./guess_game games_with_errors.txt

У Windows (PowerShell) запуск виглядає так: .\guess_game.exe та .\guess_game.exe games_with_errors.txt.

Збирання за допомогою CMake:
cmake -S . -B build
cmake --build build

Після збирання вхідні файли автоматично копіюються до папки з виконуваною програмою.

Результат роботи
Під час виконання програма виводить:

- номер поточної гри;
- кожну спробу вгадувача;
- відповідь загадувача;
- кількість кроків, за яку число було вгадано;
- переможця гри.

Після завершення всіх ігор виводиться загальний підсумок із кількістю перемог кожної сопрограми.
